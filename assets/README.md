To-Do List

Uma lista de tarefas simples, criada para praticar HTML, TailWind CSS, JavaScript e melhorar meus conhecimentos em desenvolvimento web.

A ideia do projeto foi criar uma aplicação simples onde o usuário consegue adicionar, editar, concluir e remover tarefas de forma rápida e organizada.

Funções criadas

- Adicionar tarefas 
- Editar tarefas
- Remover tarefas
- Marcar tarefas como concluídas
- Adicionar tarefas pressionando Enter

Linguagens usadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

O que foi praticado

Neste projeto pratiquei:

- Manipulação do DOM
- Criação de elementos com JavaScript
- Uso de eventos
- Funções em JavaScript
- Interação entre HTML, CSS e JavaScript

O que poderá ser melhorado

- Salvar tarefas no navegador usando LocalStorage
- Adicionar categorias para tarefas
- Criar filtros de tarefas concluídas e pendentes
- Melhorar o design da interface


Esse projeto faz parte do meu aprendizado em desenvolvimento web e foi criado para colocar em prática conceitos importantes de JavaScript, HTML, Tailwind CSS e levando em conta o cenário do desenvolm=vimento atual também foi utilizado IA, criando uma aplicação simples e funcional.
